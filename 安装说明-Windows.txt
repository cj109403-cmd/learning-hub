学习台 LearningHub · Windows 安装说明

学习台在你自己的电脑上运行，不用注册账号，学习记录只保存在这个文件夹里。
它用 Microsoft Edge 显示自己的窗口，请保留 Edge。

一、先装 Python（只做一次）

1. 打开 https://www.python.org/downloads/ ，下载并安装 Python 3.9 或更新的版本。
2. 安装时保持默认选项，确保安装了 py 启动器（Python Launcher）。
3. 已经用 Miniforge/Anaconda 的话，也可以建一个名为 learn 的环境（Python 3.9 以上）代替。

二、放好学习台

1. 在 GitHub 页面点 Code → Download ZIP。
2. 在下载的 ZIP 上点右键 → 全部解压。不要直接在压缩包里双击运行。
3. 把解压出来的整个文件夹放到一个固定位置，例如 C:\Users\你的用户名\学习台。
   不要放进 OneDrive 同步的文件夹。

三、安装快捷方式

1. 打开这个文件夹，双击“安装学习台.cmd”。
2. 如果 Windows 提示“已保护你的电脑”，点“更多信息”→“仍要运行”。
3. 看到“已创建桌面和开始菜单快捷方式”就完成了。
   以后双击桌面上的“学习台”即可打开。

四、日常使用

- 关闭窗口即可退出。后台会在一段时间后自动停止（最长约 30 分钟）。
- 学习记录在文件夹里的 progress\ 中。换电脑或升级前，把 progress 文件夹复制一份备份。
- 自带的是三张卡的示例课。想学自己的课程，按 docs\CONTENT_SPEC.md 的格式写好，
  替换 content\ 和 data\ 两个文件夹。

五、升级到新版本

1. 先关闭学习台，把旧文件夹里的 progress 文件夹复制到桌面备份。
2. 下载并解压新版本，放在原来的位置（可以先把旧文件夹改名留着）。
3. 把备份的 progress 文件夹复制进新文件夹（如果换过自己的课程，content 和 data 也一起复制），
   再双击“安装学习台.cmd”一次。
