# 学习台应用图标：暖白 + 渐变橙（2026-10-14）

暖白背景、橙色线条书本，橙色从上到下由亮到深。

- `AppIcon.iconset/`：macOS 图标集，用 `iconutil -c icns AppIcon.iconset` 生成 .icns。16 和 32 像素用的是线条加粗的小尺寸版本，不要自己再缩放。
- `learning-hub.ico`：Windows 图标，含 16、24、32、48、64、128、256 像素；16–32 像素用加粗版本。
- `learning-hub-icon-macos-1024.png`：1024 主图，按 macOS 图标网格（主体 824）对齐。
- `learning-hub-icon.svg`、`learning-hub-icon-small.svg`：矢量源文件（标准版、小尺寸加粗版）。

书本图形参考了 Lucide 的 book-open 图标（ISC 许可），按应用图标的要求重新绘制了比例和弧线。
