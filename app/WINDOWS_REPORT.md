## 已修复

1. **内容更新无法成功：** Windows 对只读文件句柄执行 `fsync` 会报错。备份、暂存和回滚副本改用可写但不截断的句柄同步；Mac 保留原有方式。
2. **校验器路径检查遗漏：** Python 3.14 的 Windows 元数据快捷路径绕过原 `stat` 包装，部分存在性检查还会吞掉 `OSError`。现在在实际文件访问前保护这些入口，使用不会被当作“文件不存在”的拒绝异常；未知校验脚本仍被拒绝，认可名单未扩大。
3. **缺失日期导致页面或导出报错：** UTC+8 Windows 无法可靠转换本地 1970 年纪元时间。缺失或无效日期使用明确的 UTC 排序兜底值，正常带时区日期保持原语义。
4. **含空格路径定位错误：** Explorer 的 `/select,` 与文件路径分为两个参数，避免引号包含开关后误开默认目录；仍不经过命令解释器。
5. **连续刷新偶发连接拒绝：** HTTP 待接收连接队列从 5 增至 32。真实 16 连接回归在旧值下失败、新值下全部返回 200；修改后完整浏览器走查通过。
6. **断线响应与提前拒绝：** 正常关闭连接不再打印 Windows 10053 堆栈或二次发送 500。提前拒绝的小请求体只做有界丢弃，最多 1,000,000 字节、总等待 250 毫秒，不解析、不执行业务；Host、Origin、会话令牌和磁盘错误处理保持原保护。

测试快照统一用正斜线；恶意 ZIP 测试保留真正的反斜杠条目，不让 Windows 的 ZIP 构造器预先规范化。安全断言没有放宽。
