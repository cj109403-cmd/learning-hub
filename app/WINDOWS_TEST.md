# Windows 安装与真机测试

2026-10-03 已在 Windows 11、Python 3.14.5 和本机 Edge 上执行自动测试与临时副本验收；具体结果、修复及尚需人眼确认的项目见 [Windows 验收报告](WINDOWS_REPORT.md)。下面的清单可用于另一台电脑复测。请用测试副本，先不要迁移已有学习记录；遇到失败，保留提示原文和 `logs/`。

## 1. 准备一次

1. 收到 `learning-hub-share-*.zip` 后，右键 → 全部解压。把里面的 `learning-hub` 文件夹放到 `C:\Users\<你的用户名>\learning-hub` 等自己可写、长期保留的位置。不要放进 OneDrive 同步的“文档”或“桌面”，不要直接在 ZIP 内运行，也不要放到 Program Files。
2. 确认 Microsoft Edge 能打开。本版本使用 Edge 的独立应用窗口，没有地址栏和标签页；需要保留 Edge。
3. 打开开始菜单，输入 PowerShell，普通打开即可，不用管理员。输入 `py -3 --version`；若显示 Python 3.9 或更新版本，可以继续。
4. 如果没有 Python，请从 [Python 官方下载页](https://www.python.org/downloads/) 安装 Python 及 `py` 入口。当前官方提供 Python Install Manager；按其[Windows 使用说明](https://docs.python.org/3/using/windows.html) 安装一个 Python 3 运行环境后，再检查上面的命令。已有 conda `learn` 环境（Python ≥3.9）也可以，不需要安装额外包。

## 2. 安装快捷方式

1. 在文件资源管理器打开刚解压的 `learning-hub`，进入 `app` → `windows`。
2. 在地址栏输入 `powershell` 并回车。这个窗口应在 `app\windows` 目录中。
3. 输入以下命令并回车：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
   ```

4. 看到“已创建桌面和开始菜单快捷方式”后，关闭 PowerShell。以后双击桌面“学习台”，或从开始菜单打开即可；日常启动不出现黑色命令行窗口。

`-ExecutionPolicy Bypass` 只用于这一次安装脚本进程，不更改系统或当前用户的长期执行策略；含义见 [Microsoft 官方说明](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_execution_policies)。只运行你确认来源的这份脚本。受单位策略管理的电脑若禁止运行，不要修改全局策略绕过，记录提示反馈。

快捷方式指向解压目录中的 `app\windows\launch.pyw`。不要删除整个项目；搬到别处后重新执行安装即可。安装脚本只创建当前用户的两个快捷方式，不写注册表、不要求管理员、不安装后台开机服务。

## 3. 逐项验收

| 检查 | 操作 | 应该看到什么 |
|---|---|---|
| 首次打开 | 双击桌面“学习台” | 独立 Edge 窗口，清透欢迎页，无终端黑窗；从 A1 开始 |
| 再次打开 | 已打开时再点快捷方式 | 复用同一项目后台；原记录不重置，没有生成多个后台服务 |
| 学习与输入 | A1 的“练”里写回答，点对照并自评，在“结”写总结，完成 | 输入保存状态明确，完成后 A2 解锁 |
| 关闭和重开 | 点击窗口关闭，等 65 秒，再双击图标 | 后台会退出；重开后 A1 记录和阶段仍在 |
| 草稿 | 在任务题中输入但不点“检查答案”，关闭后重开 | 有待处理草稿提示；由你恢复或两次确认丢弃，不自动判题、不自动删除 |
| 快捷键 | Ctrl+K 搜索、Esc 关闭，输入框 Ctrl+C/V/Z，Ctrl+Enter | 提示显示 Ctrl，操作正常，打字不会触发单字母导航 |
| 设置 | 切换纸页/清透、浅/深、字号后关闭重开 | 设置保留；没有改 Windows 系统的显示或动效设置 |
| 布局 | 900px 以上窗口与最大化窗口分别滚动路线和长卡 | 页面无横向滚动；侧栏持续占满窗口高度，文字不被遮挡 |
| 任务数据 | 在任务卡的数据文件旁点“在文件管理器中显示” | 资源管理器打开并选中当前数据文件，无额外命令窗口 |
| 外部资源 | 点击卡片资源链接 | 在浏览器中打开；本地窗口仍可继续学习 |
| 检查更新 | 把 Claude 的较新 ZIP 放到 Windows 的“下载”，设置→课程内容→检查更新 | 显示文件名、前后版本和新增卡，不自行应用 |
| 应用更新 | 核对后点“更新” | 期间暂停保存，完成后自动重载；原记录完整、新卡有标签 |
| 拒绝非法包 | 只在此测试副本中使用 Codex 提供的非法路径/校验失败测试包 | 中文原因明确；替换前拒绝或替换后恢复原课程，学习记录不变 |

没有较新更新包时，“没有新的课程更新”是正常结果。不要为测试自行修改真实课程或记录；需要失败样本时请 Codex 生成专用测试包。外部视频依赖网络，和本地离线学习分开记录。

**开发机的内容同步：** 按 CODEX_BRIEF 第 17 节，Claude 的正式更新包只在 Mac 应用并推送，Windows 开发仓库通过 Git 拉取。上表的应用内更新验收只在临时副本中执行；使用分享包的普通学习电脑仍可正常使用应用内更新。

## 4. 确认后台已经退出

1. 先关闭所有属于这个测试项目的学习台窗口，等 65 秒。正在保存或更新时，服务会先完成操作再退出。
2. 打开任务管理器 → 详细信息，在列表表头右键 → 选择列 → 勾选“命令行”。
3. 查找命令行同时含 `app.server.main` 和这个测试目录的 `pythonw.exe`：正常应已消失。不要结束其他 Python 或 Edge 进程。
4. 如果仍存在，记下等待时长、完整命令行中这个测试项目对应的部分和当时是否正在更新，反馈给 Codex。

Edge 使用 `%LOCALAPPDATA%\LearningHub\Browser\<项目编号>` 下独立资料目录；后台端口变化不会丢掉磁盘草稿。不会读取或清理你日常 Edge 的个人资料。

## 5. 可选：运行自动测试

在项目根目录打开 PowerShell，执行：

```powershell
py -3 -B -m unittest discover app/tests -q
```

测试使用临时目录，不用真实 `progress/` 或 `workspace/`。记录最后的测试数量、OK/FAILED 及错误堆栈。Mac 原生构建测试会按平台跳过；不要把跳过理解为 Windows 功能已验证。
