学习台 · Windows 安装说明
课程版本：2026-10-14.1，共 43 张卡
说明更新：2026-10-14

这是给你自己的学习台。不用装 Git 或 Codex，也不用注册账号。
第一次准备好以后，双击桌面上的“学习台”就能打开。
请保留 Microsoft Edge；学习台用它显示自己的窗口。

一、先装 Python（只做一次）

1. 用浏览器打开这个 Python 官方页面：
   https://www.python.org/downloads/release/python-3148/

2. 往下找到 Files，点击 Windows installer (64-bit)。
   下载的文件名应是 python-3.14.8-amd64.exe。
   这里选择的是普通安装程序，不是页面上方的 Python install manager。
   本说明按常见的 Intel / AMD 64 位 Windows 电脑编写。
   如果电脑“设置 → 系统 → 关于/系统信息”里写的是 ARM64 或基于 ARM 的处理器，
   在同一页面改选 Windows installer (ARM64)。

3. 双击下载好的安装程序。
   在第一个窗口勾选 Add python.exe to PATH。
   Use admin privileges when installing py.exe 保持不勾选。
   然后点击 Install Now，其他选项用默认值即可。
   默认安装会带上学习台需要的 py 启动器，不用另找安装包。

4. 如果弹出“是否允许此应用对你的设备进行更改”，
   确认这是刚从 python.org 下载的 Python 安装程序，
   发布者是 Python Software Foundation，再点“是”。
   默认的个人安装可能不会出现这个窗口。

5. 看到 Setup was successful 后，点 Close。
   如果出现 Disable path length limit，可以先不点，直接 Close。
   现在不需要另外输入命令或安装任何 Python 工具包。

二、把学习台放到一个长期保留的位置

1. 找到收到的 learning-hub-share-windows-2026-10-14.1.zip。
   先右键点这个 ZIP → 属性。
   如果底部有“解除锁定”或“取消阻止”，勾选后点“应用”→“确定”；
   没有这项就直接关闭属性窗口。

2. 右键点 ZIP → 全部解压 → 解压。不要直接在 ZIP 里面打开程序。
   打开解压出来的文件夹，找到里面名叫 learning-hub 的文件夹。
   打开它应能看到“安装说明”“安装学习台”和 app、content、data 等文件夹。
   Windows 可能隐藏 .txt 和 .cmd 后缀，这是正常的。

3. 回到上一层，选中这个 learning-hub 文件夹，按 Ctrl+X。
   按 Win+E 打开一个新的“文件资源管理器”窗口。
   点最上面的地址栏（显示文件夹路径的那一行），输入：
   %USERPROFILE%
   按回车，再按 Ctrl+V。

4. 放好以后，位置应该类似：
   C:\Users\你的用户名\learning-hub
   其中“你的用户名”是电脑已经显示的名字，不用自己照着改。
   请确认地址里没有 OneDrive。
   不要放到桌面、文档、OneDrive、Program Files 或临时下载目录。
   桌面上以后放的是快捷方式，完整的 learning-hub 文件夹留在这里。

三、安装桌面入口

1. 打开刚放好的 learning-hub 文件夹。
   双击“安装学习台.cmd”（类型可能显示为“Windows 命令脚本”）。
   不需要右键选择“以管理员身份运行”。

2. 安装时可能短暂出现一个黑色窗口，稍等一下。
   看到“已创建桌面和开始菜单快捷方式‘学习台’”后，点“确定”。
   这就装好了。桌面和开始菜单里会出现“学习台”，
   图标是一盏台灯照着摊开的笔记本。

3. 以后双击桌面“学习台”即可，不必每次再运行安装脚本。
   完整文件夹不能删除或搬走；它是快捷方式实际打开的位置。
   如果确实搬了位置，在新位置重新双击“安装学习台.cmd”。

四、如果 Windows 弹出安全提示

这些操作只适用于你确认是刚收到的这份学习台，
以及从 python.org 下载的 Python 安装程序。

• 提示“Windows 已保护你的电脑”：
  点“更多信息”，确认文件名是你刚打开的文件，再点“仍要运行”。
  如果没有“仍要运行”，先停下来，把提示截图发给给你安装包的人。

• 提示“打开文件 — 安全警告”，问是否运行：
  核对是刚打开的学习台安装文件后，点“运行”。

• 提示找不到 Python：
  完成第一节的 Python 安装后，关闭安装窗口，再双击“安装学习台.cmd”。
  仍然失败时把完整提示发给给你安装包的人。

• 提示组织策略、智能应用控制阻止运行，或明确检测到病毒：
  不要关闭杀毒软件、不要关闭系统保护，也不要修改全局执行策略。
  把提示发给给你安装包的人，请对方协助处理。
  这份安装入口已经处理了一次安装所需的脚本运行方式。

• 如果 Windows 防火墙询问是否允许 Python 通过网络：
  学习台只在这台电脑内部运行，不需要开放给其他电脑。
  点“取消”即可；不需要勾选公共网络。

五、第一次打开，以及以后每天怎么用

1. 双击桌面“学习台”。会打开一个独立窗口。
   第一次会看到“欢迎加入。”和课题组介绍，点击“从 A1 开始”。
   这是你自己的全新学习记录，不需要登录，也不会带有别人的进度。

2. 卡片分“学 → 练 → 结”三个阶段，按页面提示读、练、写总结。
   在“设置 → 课程内容”可以确认版本为 2026-10-14.1。
   这一版共有 43 张卡：Python 14 张、统计学 16 张、数据处理 13 张。
   一句话总结可以不写；写不出来时点“写不出来？看看这节的要点”。

3. 写完文字后，等输入区域显示“已保存到这台电脑”，再关闭窗口。
   如果提示有未保存内容或“查看草稿”，先按提示处理。
   关闭窗口后，后台还会在电脑里多留一会儿（最长 30 分钟）再自动退出。
   这是已知情况，不影响学习记录，不用管它。

4. 正式记录保存在 learning-hub 里的 progress 文件夹。
   不要删除它，也不要把自己的记录发给别人。
   平时可以在关闭学习台并重启电脑后，
   把整个 progress 文件夹复制到一个自己保管的备份位置。
   “导出学习记录”只是便于阅读的摘要，不能代替完整 progress 备份。

六、以后收到“课程更新包”怎么更新

课程更新包的名字类似 learning-hub-update-20261005-1.zip，
与首次安装用的 learning-hub-share-...zip 不同。

1. 把收到的课程更新 ZIP 保存到 Windows 的“下载”文件夹。
   直接放在“下载”里，不要再套一层文件夹，不要解压，不要改文件名。
   如果文件目前在聊天软件的下载目录，用文件资源管理器把 ZIP
   复制到左侧“下载”里。

2. 打开学习台，先让当前文字保存成功。
   如果有“查看草稿”，先恢复需要保留的文字并保存。
   恢复任务答案后，还要点一次“检查答案”。
   不要为了更新而丢弃自己还需要的文字。

3. 点左下角“设置”→ 找到“课程内容”→ 点“检查更新”。
   核对显示的 ZIP 名称、旧版本和新版本，然后点“更新”。
   等待完成和页面重新载入，期间不要关闭窗口。

4. 完成后再看“课程内容”的版本号。
   原来的答案、总结、完成进度和设置会保留，新增卡片会出现。

如果提示没有新版本：检查 ZIP 是否确实放在“下载”顶层，
以及它的课程版本是否比当前更新。
如果提示有草稿：先点“查看草稿”，处理后回到设置继续。
如果提示“课程内容检查未通过”：把提示和更新包发给给你安装包的人，
先继续用现有课程（它不会被改动）。
如果更新失败：按界面提示处理，保留现有文件，不要自行删 backups。

七、以后换“新版程序分享包”，怎样保留你的记录

只有课程有新内容时，按第六节更新就够了。
需要升级程序本身时，发送者会明确告诉你，并发来新的 share ZIP。
这种包不能在应用里的“检查更新”中安装。

请按下面顺序换包，不要直接覆盖整个旧文件夹：

1. 在旧版设置中记下课程版本。
   新分享包附的课程版本应不低于它；如果更早，请让发送者重新打包。
   不确定时先把版本号告诉发送者，继续使用旧版。

2. 在旧版中处理所有“查看草稿”提示，
   确认需要的文字都显示“已保存到这台电脑”，且没有正在进行的更新。
   关闭所有学习台窗口，然后重启电脑（关闭窗口后后台最长还会留 30 分钟，
   重启最省事）。重启不能代替保存。

3. 用文件资源管理器打开原来的 learning-hub。
   复制里面整个 progress 文件夹，另存到你自己保管的备份文件夹，
   例如在用户目录中建“学习台记录备份-日期”。
   要复制整个文件夹，包括设置、草稿、备份等；不要只复制一个 JSON，
   不要打开或手工修改里面的文件。

4. 回到上一层，把旧 learning-hub 改名为 learning-hub-旧版保留。
   如果提示正在使用，先不要强行操作；确认窗口已关，
   再等一会儿，必要时重启电脑后重试。

5. 把新分享 ZIP 完整解压。
   将新版里完整的 learning-hub 文件夹放到旧版原来的位置，
   恢复原来的名字，例如 C:\Users\你的用户名\learning-hub。
   先不要打开新版。这时旁边应同时有“learning-hub”和“learning-hub-旧版保留”。

6. 从“learning-hub-旧版保留”里复制整个 progress，
   粘贴到新版 learning-hub 里面，与 app、content、data 并排。
   最后的结构应是 learning-hub\progress\progress.json，
   不能多套一层 progress。
   新分享包本身不应该含有 progress；如果已经存在，先不要覆盖，
   请让发送者帮你核对。
   如果你自己另建过 workspace 文件夹保存代码或笔记，也自行把它
   整个复制到新版同一层。这些练习文件不在 progress 里。

7. 双击新版的“安装学习台.cmd”，更新桌面入口。
   再从桌面打开“学习台”，核对完成数量、最近的总结和设置是否还在。
   如果以前已经学过，却又出现全新的欢迎页或进度为空，
   先关闭，不要重新开始学习；保留新旧两个文件夹和备份，找发送者协助。

8. 确认几次打开都正常以前，保留旧文件夹和额外的记录备份。
   恢复原来的文件夹位置还能保留浏览器里与该位置关联的状态。
   不要清理 Edge 的学习台数据来“重装”，也不要直接用旧程序覆盖回新版。
   遇到问题，先把报错和版本号发给发送者，不用发送你的学习记录。
